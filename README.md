# Laboratory Work 3 — Functions and Methods

JavaScript exercises based on the HowProgrammingWorks/Function repository.

## Implemented tasks

1. `random(min, max)` — generates a random integer in the specified range.
2. `generateKey(length, characters)` — generates a random key.
3. `ipToNumber(ip)` — converts an IPv4 address to a 32-bit number.
4. Object introspection — returns method names and parameter counts.

## Installation

```bash
npm install
```

## Run tests

```bash
node --test
```
